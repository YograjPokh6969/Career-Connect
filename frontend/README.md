# Career Connect — Frontend

This is the frontend-only scaffold for the Career Connect campus placement portal.

Tech stack:
- React + Vite
- Tailwind CSS
- React Router DOM
- React Icons

To run:

1. Install dependencies:

```bash
npm install
```

2. Start dev server:

```bash
npm run dev
```

This initial commit includes the public pages: Home, Jobs, Job Details, Login, Register; layout, navbar, footer, and dummy job data.
